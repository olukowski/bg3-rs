# bg3_bevy (working title)

An experimental, open-source reimplementation of **Baldur's Gate 3** in Rust on Bevy, aiming for
1:1 behaviour with the original. It contains **no game files**: it reads everything from your own
installed copy of BG3.

Status: pre-alpha — workspace and research only. See [`docs/roadmap.md`](docs/roadmap.md).

## Requirements

- A legally obtained copy of Baldur's Gate 3 (reference build: 4.1.1.7631656, macOS Steam).
- Rust stable.
