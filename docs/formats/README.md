# File formats

Our own descriptions of BG3 file formats, written in our own words as we implement them. One file
per format (`pak.md`, `lsf.md`, `gr2.md`, `osiris-story.md`, …).

Each write-up should include: layout, versions seen in the reference build, quirks, how it was
verified (which paks/files), and credits to prior art (e.g. LSLib) where it informed us.
